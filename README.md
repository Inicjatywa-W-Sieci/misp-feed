# Inicjatywa W Sieci – MISP Threat Intelligence Feed

Public Threat Intelligence feed maintained by **Inicjatywa W Sieci** ([inicjatywawsieci.eu](https://inicjatywawsieci.eu)), an independent Polish non-profit cybersecurity and OSINT monitoring initiative.

## Scope & Content
* Active phishing domains and URLs targeting Polish users and institutions
* Malicious infrastructure, scam campaigns, and credential harvesting sites
* Verified OSINT indicators (`TLP:CLEAR`)

## Feed URL (MISP Format)
Add this URL to your MISP instance (**Sync Actions -> List Feeds -> Add Feed**, format: `MISP Feed`):
`https://githubusercontent.com`

## Update Frequency & License
* **Updates:** Automated sync every 15 minutes
* **Classification:** `TLP:CLEAR`
* **License:** Open data for defensive cybersecurity purposes
